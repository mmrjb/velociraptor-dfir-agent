# Preview roadmap

- Complete real lab API, Ollama, browser and MCP acceptance checks.
- Review code provenance and select a project license before public publication.
- Improve evidence navigation from lab feedback without adding collection/response features.

Notebook/Master Triage and a full Velociraptor UI replacement remain in the separate internal
project. They are not promised as working capabilities of this preview.

Follow-up work deliberately outside 0.5.0a1:

- A process/file/user/network relationship explorer across many investigations (0.5.0a1
  shows observed parent/child and same-capture links in the inspector only).
- Dashboard builders, widget marketplaces, arbitrary chart or query editors.
- Multi-user case management, assignments or chat.
- Additional LLM providers, embeddings, autonomous agents, model training.
- New collection/response features, arbitrary VQL, a broad Velociraptor GUI replacement.
- Automatic third-party reputation or enrichment lookups.
- The internal edition's Notebook-cell adapter (contract in docs/presentation.md).
- Usability timing with analysts against 0.4.0a2 and the Velociraptor GUI.
